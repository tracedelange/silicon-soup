Drawing an overlay
  1. Canvas 64x64, transparent background. Full width — a weapon is asymmetric, so it can't use the body's mirror trick.
  2. Paint in these five key grays only. Each maps to the material's ramp stop at the same index, darkest to lightest:
064 128191 255
  1. Use step 0 for the outline, step 4 for specular highlights. Nearest stop wins, so a gray that's a few off still lands right.
  2. Align to the pose guide — toggle it above, or download it as an Aseprite reference layer.
  3. Save as client/public/gear/<name>.png: the archetype id for a weapon (sword, maul), or chest_light / chest_heavy / helmet_light / helmet_heavy for armor.
No registry to update — a file appearing is what makes an overlay real, and a missing one just doesn't draw.
